RNF01. O sistema deverá ser desenvolvido utilizando HTML, CSS e JavaScript no frontend. RNF02. O backend deverá ser desenvolvido em PHP. RNF03. O banco de dados deverá utilizar MySQL, administrado pelo phpMyAdmin. RNF04. As senhas deverão ser armazenadas utilizando funções de hash do PHP (password_hash() e password_verify()). RNF05. O sistema não deverá armazenar senhas em texto puro. RNF06. O sistema deverá possuir interface responsiva para computadores e dispositivos móveis. RNF07. O tempo médio de carregamento das páginas não deverá ultrapassar 3 segundos em condições normais. RNF08. O sistema deverá apresentar mensagens claras em caso de erro ou sucesso das operações. RNF09. O sistema deverá possuir interface simples, intuitiva e de fácil navegação. RNF10. Apenas usuários autenticados poderão acessar as funcionalidades do sistema. RNF11. Apenas administradores poderão cadastrar usuários e alterar permissões. RNF12. O sistema deverá garantir a integridade dos dados armazenados no banco. RNF13. O sistema deverá utilizar Git e GitHub para controle de versões. RNF14. O código deverá seguir organização em arquitetura escolhida pela equipe (Arquitetura em Camadas ou Pipeline). RNF15. O sistema deverá ser compatível com os principais navegadores (Google Chrome, Microsoft Edge e Mozilla Firefox). RNF16. O sistema deverá manter consistência dos dados durante importações de planilhas. RNF17. O sistema deverá registrar erros de importação e informar quais registros não puderam ser importados. RNF18. O sistema deverá permitir manutenção e expansão do código de forma organizada.
